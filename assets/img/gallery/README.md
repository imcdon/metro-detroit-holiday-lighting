# Gallery photos

Drop finished project **JPEG/PNG** masters via the export sync scripts (preferred), or place optimized `.jpg` / `.png` files here.

- Public gallery index lists JPEG/PNG only (not `*-800w.webp` variants).
- WebP width variants and `.variants-manifest.json` are generated by `bin/optimize-mdhl-gallery.py`.
- Prefer: `python bin/sync-ranch-exports.py` or `python bin/sync-bloomfield-exports.py` after dropping files in `assets/img/Untitled Export/`.
